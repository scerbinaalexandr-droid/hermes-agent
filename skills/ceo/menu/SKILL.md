# CEO Menu — main entry point

**Purpose.** CEO не должен помнить 7+ slash-команд. `/menu` — single point of
reference. Показывает все CEO commands со one-line описанием и use case.

**Trigger.** `/menu`, `/start`, `/help`, "что ты умеешь", "что я могу".

## Output (Telegram, ≤ 1500 char, на русском)

```
🤖 *Гермес — ассистент и банк контекста*

*Каждый день:*
🎙 /capture — мысль, задача, решение голосом → разложу по направлениям
📋 /notes — протокол встречи: решения, задачи, ответственные
✅ /tasks — задачи по срокам; «поставь задачу по Бадену: что, кто, срок»
📊 /brief — утренний дайджест по направлениям (авто 07:30)
🌙 /evening — вечерний дневник голосом (авто 21:00)
📔 /diary — дневник и протоколы
🌅 /morning — утренний фокус (авто 06:50)

*Еженедельно:*
📅 /week — обзор недели П1–П5 голосом (авто вс 18:00)

*В дороге:*
🚗 Дорога — каждый ответ голосом · 💬 Текст — обратно
🧠 Глубже — думать сильнее над сложной задачей · ⚡ Обычно — обратно

*Поручения работникам:*
📨 /assign — «поручи ресерчеру / аналитику / протоколисту / редактору …»; итог придёт сюда, отчёт — в карточке

*Найти и вспомнить:*

*Утилиты:*
```

## Keyboard (hands-free)

ВСЕГДА заканчивай ответ строкой `[[menu_keyboard]]` на отдельной строке — гейтвей
превращает её в постоянную клавиатуру-плитки под полем ввода (большие кнопки за
рулём). НЕ объясняй маркер и НЕ убирай его — в видимом тексте он не показывается.

## Edge cases

| Случай | Поведение |
|---|---|
| Первый раз user пишет `/start` | Покажи menu + строку «Привет, Александр. Гермес на связи.» |
| Telegram payload limit | ≤4096 char — текущий menu helps stay well under |

## What NOT to do

- ❌ Не показывай вторично если уже показал в этой session (cooldown 30 мин)
- ❌ Не давай длинные tutorials — это reference card, не doc
- ❌ Не предлагай функций, которых нет в списке
