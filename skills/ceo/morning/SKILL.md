# Morning — личный утренний ритуал

**Purpose.** Спокойное начало дня ДЛЯ СЕБЯ (не рабочий план — то `/brief`/«День»):
короткая медитация → напоминание на чём фокусироваться → проговорить вслух.
Это раздел «Личное».

**Trigger.** `/morning`, фразы выше, ИЛИ cron 06:50 EEST.

## Step 1 — Gather (deterministic)

```bash
python skills/ceo/morning/scripts/morning.py --gather
```

Возвращает `{meditation, focus[], count}` — медитация-кью на сегодня + сохранённый
личный фокус Александра (вкладка «Фокус»).

## Step 2 — Если фокус ещё не задан (`count == 0`) → онбординг

Не выдавай пустой ритуал. Тёпло предложи задать:

```
🌅 Доброе утро, Александр.

Давай настроим твой утренний фокус — на чём хочешь фокусироваться и что
проговаривать каждое утро? Это могут быть ценности, настрой, цель, мантра.

Надиктуй голосом — я сохраню, и каждое утро буду напоминать.
```

Когда надиктует — сохрани каждый пункт:
```bash
python skills/ceo/morning/scripts/morning.py --save '{"text": "<пункт фокуса>"}'
```

## Step 3 — Ритуал (если фокус есть)

```
🌅 *Доброе утро, Александр.*

🧘 _{meditation}_

🎯 *Твой фокус — проговори вслух:*
• {focus 1}
• {focus 2}
…

Сделай это своим. Спокойного и собранного дня.
```

- Тон тёплый, спокойный, без рабочей суеты (это личное).
- Это ритуал, НЕ черновик — без `[[draft_actions]]`.

## Step 4 — Добавить / убрать фокус

- «в утренний фокус добавь: …» / «добавь к фокусу …» → `--save '{"text": "…"}'`, подтверди ≤1 строкой.
- Убрать пункт — пока вручную: удалить строку во вкладке «Фокус» (подскажи как, если спросит).

## Edge cases

| Случай | Поведение |
|---|---|
| `count == 0` | онбординг (Step 2), не пустой ритуал |
| Sheet недоступен (`reason`) | покажи медитацию + «фокус подгружу позже» |
| Дал длинную надиктовку | разбей на отдельные пункты, сохрани каждый |

## What NOT to do

- ❌ Не путай с `/brief` (рабочий план дня) — `/morning` про ЛИЧНОЕ: настрой, ценности.
- ❌ Не навязывай свои формулировки — фокус ЕГО; ты только бережно сохраняешь/напоминаешь.
- ❌ Без privacy-нарушений: если в фокусе личное/чувствительное — храни как есть, не комментируй.
