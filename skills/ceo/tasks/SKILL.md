# Задачи на досках

**Назначение.** Одно место для всех задач владельца. Ставятся голосом на ходу,
раскладываются по направлениям, контролируются по срокам. Доски он смотрит в
приложении Hermex; здесь — постановка, просмотр и закрытие разговором.

**Важно.** Google-таблица «Задачи» больше НЕ используется для новых задач —
она осталась архивом. Не предлагай её и не пиши туда.

## Доски

| Доска (slug) | Что туда |
|---|---|
| `lichnoe` | личное, семья, здоровье, хобби, покупки |
| `moldova` | Молдова: UCC, CRM, продажи и операции MD |
| `romania` | Румыния: шоурумы, лиды, ценообразование |
| `proizvodstvo` | фабрики, качество, логистика, монтаж |
| `partnery` | Albumo, WhiteDecor, Arlengo, Vital Flow и прочие партнёры |
| `finansy-yur` | платежи, налоги, договоры, юридическое |

Актуальный список — всегда из `--boards`, а не из этой таблицы.

## Поставить задачу

```bash
python skills/ceo/tasks/scripts/kanban_ops.py --add --board <slug> \
  --title "<что сделать>" [--assignee "<кто>"] [--due YYYY-MM-DD] [--note "<детали>"]
```

Как определять поля из речи:

- **Доска** — по смыслу (см. таблицу). Если direction неочевидно — спроси одной
  фразой: «На какое направление? Молдова, Румыния, Производство, Партнёры,
  Финансы, Личное?»
- **Срок** — переводи в дату: «до пятницы», «завтра», «к концу месяца» → дату.
  Сегодняшнюю дату бери из `--list` (поле `today`), НЕ выдумывай.
- **Ответственный** — если названо имя, ставь его. Если не названо и задача
  рабочая — спроси: «Кто ответственный?» Для личных задач ответственного не
  спрашивай — это владелец.
- **Заголовок** — короткий и по делу, деталей не теряй: длинное уходит в `--note`.

Спрашивай МАКСИМУМ одно-два уточнения за раз. Владелец диктует за рулём — не
устраивай допрос. Чего не хватает — оставь пустым, добавит позже.

После создания подтверди одной строкой:
`✅ {заголовок} → {доска}{, ответственный}{, срок}`

## Показать задачи

```bash
python skills/ceo/tasks/scripts/kanban_ops.py --list [--board <slug>] [--days 7]
```

Возвращает `{today, total_open, overdue[], soon[], later[], no_due[]}`.

Формат ответа:

```
📋 *Задачи — {total_open}*

🔴 *Просрочено:*
• {заголовок} — {ответственный} · {срок} (на {days_late} дн.) · {доска}

🟡 *Ближайшие:*
• {заголовок} — {ответственный} · {срок} · {доска}

⚪ *Без срока:*
• {заголовок} — {ответственный} · {доска}
```

- Пустые блоки не печатай.
- Больше 15 задач — покажи все просроченные и ближайшие, из остальных первые 5
  и «… ещё N».
- Спросили про направление («что по Румынии») — добавь `--board romania`.

## Закрыть задачу

```bash
python skills/ceo/tasks/scripts/kanban_ops.py --done <task_id> [--board <slug>]
```

Номера задач владелец не помнит — он говорит «закрой подарок Фирюзе». Сначала
`--list`, найди по смыслу заголовка, потом закрывай. Если подходит несколько —
переспроси, какую именно. Подтверди: `✅ Закрыто: {заголовок}`.

## Чего не делать

- ❌ Не писать новые задачи в Google-таблицу — только доски.
- ❌ Не выдумывать задачи, сроки и ответственных: если не сказано — не пиши.
- ❌ Не создавать доски самовольно — только те, что есть в `--boards`.
- ❌ Не сыпать техническими деталями: номера задач показывай только если
  спросили, путей и команд в ответе быть не должно.
