# /birthday — Дни рождения в календаре CEO

**Цель:** добавлять дни рождения и годовщины в основной календарь Александра
(Hermes — owner) как **повторяющиеся ежегодные** события. Утреннее напоминание
в день ДР шлёт отдельный cron автоматически.

## Движок (НЕ himalaya — только google-workspace OAuth)

```
HERMES_HOME=/opt/data /opt/hermes/.venv/bin/python /opt/data/scripts/birthday.py \
  --add --name "ИМЯ" --day Д --month М [--year ГГГГ] [--kind wedding]
```

## Steps (добавление)

1. **Распарсить запрос CEO** → имя + день + месяц (+ год если назван).
   - «добавь ДР Маши Ивановой 15 марта 1990» → name="Маша Иванова", day=15, month=3, year=1990
   - «годовщина свадьбы Урсаки 5 июня» → name="Годовщина свадьбы Урсаки", day=5, month=6, kind=wedding
   - Месяц словом → числом (январь=1 … декабрь=12), принимай и родительный падеж («марта»).
2. **Если не хватает дня/месяца** — переспроси одним вопросом. Год опционален (с ним показывается возраст).
3. **Выполнить** движок (см. выше). Показать подтверждение, которое вернул скрипт.
4. **Несколько за раз** — вызвать движок по разу на каждого.

## Проверка «кто сегодня» (по запросу)

```
HERMES_HOME=/opt/data /opt/hermes/.venv/bin/python /opt/data/scripts/birthday.py --check --days 7
```
Покажет именинников сегодня + ближайшие 7 дней (с возрастом).

## Автоматизация

Утренний cron (`no_agent`, 0 токенов) каждый день проверяет именинников и шлёт
напоминание в Telegram **только если кто-то есть** (иначе молчит).

## What NOT to do

- ❌ Не использовать himalaya / другой email-CLI.
- ❌ Не выдумывать даты/имена — если CEO не назвал, переспроси (soul.md §4a).
- ❌ Не удалять/менять существующие события без явного запроса.
- ❌ Privacy: имена близких — как назвал CEO; не выгружать список третьим лицам.
