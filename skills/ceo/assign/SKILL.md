# /assign — поручения работникам

## Роли

| Роль | Кому поручать | Слова владельца |
|---|---|---|
| `researcher` | изучить рынок, найти факты/источники, сравнить | «изучи», «найди», «собери источники», «сравни» |
| `analyst` | таблицы, расчёты, выгрузки из открытых данных, Excel | «посчитай», «сведи в таблицу», «выгрузи» |
| `scribe` | транскрипт/надиктовка → резюме, решения, задачи | «расшифруй встречу», «сделай протокол из…» |
| `writer` | тексты, КП, описания, черновики писем | «напиши», «подготовь текст/КП», «черновик письма» |
| `mirror` | психоаналитический разбор человека по переписке/транскрипту или ситуации владельца | «что это за тип», «разбери его/её», «зеркалу», «почему я так реагирую» |

Роль не названа — выбери по смыслу; сомневаешься — спроси одной фразой:
«Кому поручить: ресерчеру, аналитику, протоколисту или редактору?»

### 🪞 Зеркало — особые правила

- Карточки Зеркала идут на **закрытую доску «Зеркало»** (скрипт делает это сам по роли), не на «Поручения».
- `--title` — нейтральный: «Разбор переписки», «Ситуация с партнёром», «Разговор». Название уходит в Telegram и видно в списке карточек — ничего по существу в нём быть не должно.
- Материал (переписка, транскрипт, описание) — целиком в `--brief`.
- Владелец хочет **поговорить** (не разбор, а «мне тяжело», «поговорим», «хочу разобраться в себе») — карточка не подходит. Ответь одной фразой: «Поговорить с Зеркалом — в приложении: профиль «mirror», новый чат. Там разговор остаётся только между вами.» Ничего из сказанного в память не записывай.
- В ответе после постановки: «🪞 Передал Зеркалу: <название>. Разбор будет в карточке «Зеркало».»

## Постановка (главное)

Работник начинает **с чистого листа**: он не видит этот диалог. Всё, что нужно,
кладётся в `--brief`: цель, зачем владельцу, контекст (направление PRJ-1–PRJ-5, страна,
сроки, что уже известно), что считать готовым, формат результата. Короткие
поручения расширяй сам из контекста беседы, не переспрашивая по мелочам.

```bash
python skills/ceo/assign/scripts/assign.py --role <role> \
  --title "<короткое название>" \
  --brief "<полная постановка>" [--priority 0|1|2]
```

Приоритет: «срочно/горит/первым делом» → 2, «важно» → 1, иначе 0.
`--roles` — список ролей (если владелец спрашивает, кто есть).

## Ответ владельцу (после `ok: true`)

Коротко, без служебных слов:

```
📨 Поручил ресерчеру: <название>.
Результат пришлю сюда, полный отчёт будет в карточке «Поручения».
```

Не называй id задачи, пути, статусы. При `ok: false` — одна человеческая фраза
(«Не смог поставить поручение — нужна проверка») и файл бага через /tune.

## Статус поручений

«что с поручением / поручения» → `python skills/ceo/tasks/scripts/kanban_ops.py --list --board assignments`
(карточки Зеркала — `--board mirror`, называй только заголовки)
и ответ списком: название — кто — состояние по-русски (в работе / готово / ждёт вопроса / в очереди).
«ждёт вопроса» (blocked) — приведи вопрос работника из карточки и предложи ответить:
ответ владельца добавь комментарием (`/kanban comment <id> "<ответ>"`) и разблокируй (`/kanban unblock <id>`).

## Границы

- Не ставь поручения сам без слова владельца.
- Одно поручение — одна карточка; крупную задачу разбей на 2–3 поручения и скажи об этом.
- Не больше 2 работников одновременно — если очередь, скажи «встанет в очередь».
